# Privacy statement draft

Vach Daily stores reading language, source preferences, and saved reading IDs locally on the device. The app has no account, analytics, advertising, or push notifications. Its included readings and widgets work offline. Opening an external source link, if one is included in a reviewed passage, uses the device browser and that site may have its own privacy practices.

The operating system handles widget display and scheduling. This draft must be reviewed against the final release build and store privacy forms before publication.
